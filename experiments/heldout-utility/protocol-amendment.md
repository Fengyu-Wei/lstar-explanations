# Amendment before final run: independent calibration sampling
Date 2026-10-05. Initial stratified four-way runs are preserved under exploratory-stratified-pilot and superseded for manuscript numbers.

Reason: a conditional binomial precision certificate assumes iid calibration observations independently of the fixed tree. Label-stratified calibration does not exactly meet that assumption. First draw the 20% selection/calibration indices uniformly at random without inspecting labels; then stratify the remaining data into 50% fit, 25% reference and 5% query. The conditional guarantee treats the fixed binary benchmark population as iid and remains distribution-dependent; the finite reference diagnostic does not establish deployment validity. No change to endpoints, datasets, seeds, depths, baselines, thresholds, confidence budget or query caps. Rerun main, matched Anchors and cross-model experiments with the corrected shared split function. Do not choose which run to report based on score.

This amendment is methodological correction after seeing pilot results, not original preregistration. The final runs confirm the corrected locked protocol; all pilot data remain available.

Second correction before manuscript analysis: sorting query indices then taking the first 20 can bias class-sorted source datasets. If the query partition exceeds 20, sample 20 with label-stratified random selection (seed 4000+split seed), then sort for stable identifiers. For the small Anchors benchmark, choose five random query positions without replacement (seed 5000+split seed), rather than the first five original indices. Keep the matched method comparison on exactly these positions. Preserve the intermediate query-order pilot separately, including its incomplete Anchors run. Neither correction changes the locked success criteria.
